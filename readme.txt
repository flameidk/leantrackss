LeanTrack PWA. Upload the contents of this folder to an HTTPS static host (such as Netlify Drop or GitHub Pages). Visit the resulting URL in Chrome on Android, then choose Add to Home screen / Install app. Data is stored in browser localStorage on this device; clearing browser site data or uninstalling may erase it. No account, sync, server-side AI, or encrypted cloud backup is included. Do not put an OpenAI API key in client files. For full AI integration, use a secure backend. The app has not been tested on a physical Samsung device.
